<h2>Latar Belakang Proyek</h2>

<p>NekoBox pada dasarnya merupakan klien luar biasa untuk Sing-box. Namun, pengguna sering kali harus memasang beberapa aplikasi berbeda hanya untuk mengatur koneksi proksi konvensional dan injeksi modern. Modifikasi khusus ini menjebol batasan tersebut. Kami menyuntikkan mesin SSH langsung ke dalam urat nadi Sing-box, sehingga perangkat Anda tetap hemat memori tanpa perlu mengorbankan performa jaringan.</p>

<h2>Daftar Inovasi Utama</h2>

<h3>1. Desain Antarmuka Swipe Dinamis</h3>
<p>Ucapkan selamat tinggal pada kerumitan menavigasi menu. Aplikasi ini menghadirkan dua panggung utama: satu sisi untuk <b>V2Ray</b> dan sisi lainnya khusus untuk <b>SSH</b>. Anda hanya perlu mengusap layar ke kiri atau ke kanan untuk berpindah ranah secara instan.</p>

<h3>2. Mesin Injeksi SSH Terintegrasi</h3>
<p>Tidak seperti aplikasi proksi lain yang sekadar menumpang pada aplikasi pihak ketiga, kami membangun pembungkus SSH khusus yang berinteraksi langsung dengan inti sistem jaringan. Ini memberikan stabilitas absolut untuk menembus pembatasan jaringan, berselancar di internet dengan aman, dan memutar video resolusi tinggi tanpa kendala. <i>Catatan: Untuk kebutuhan bermain gim daring kelas berat yang sangat bergantung pada protokol UDP tingkat lanjut, kami tetap menyarankan penggunaan ranah V2Ray.</i></p>

<h3>3. Pengaturan Cepat Otomatis</h3>
<p>Mengisi detail server satu per satu adalah cara kuno. Cukup tempelkan format server SSH Anda seperti <code>sg-melbi.toko-vpn.my.id:80@azzz:9201</code> pada bilah penyiapan kilat. Sistem akan membedah format tersebut dan menciptakan profil koneksi utuh dalam sekejap mata. Sisa pengaturan muatan dan proksi bisa Anda sesuaikan kemudian sesuai selera.</p>

<h2>Panduan Kompilasi Mandiri</h2>

<p>Bagi para pengembang yang ingin meracik aplikasi ini dari kode sumber, prosesnya telah diotomatisasi sepenuhnya.</p>

<ol>
  <li>Lakukan <i>fork</i> atau duplikasi repositori ini ke akun GitHub Anda.</li>
  <li>Navigasikan ke bagian <b>Actions</b>.</li>
  <li>Pilih alur kerja <b>Release Build</b>.</li>
  <li>Picu eksekusi alur kerja dan masukkan nama rilis yang Anda inginkan pada kolom yang tersedia.</li>
  <li>GitHub Actions akan mengompilasi mesin inti dan aplikasi Android secara bersamaan untuk berbagai arsitektur perangkat keras.</li>
  <li>Unduh APK dari halaman <i>Releases</i> setelah proses selesai.</li>
</ol>
